# 1.1 · Los dos CLAUDE.md — solución de referencia

## El global: tus preferencias

`~/.claude/CLAUDE.md` — vale en todos tus proyectos.

```markdown
- Respóndeme en español.
- Ve al grano. Sin resúmenes de lo que acabas de hacer salvo que lo pida.
- Antes de un cambio que toque más de tres archivos, propón el plan primero.
- Cuando algo falle, dime qué comprobaste, no qué supones.
```

Cuatro líneas. Todo lo que empiece por «yo prefiero» va aquí, **no** en el del
proyecto: si lo pones allí, le impones tu estilo a todo el equipo.

## El del proyecto: lo que vale para cualquiera

```markdown
# Reglas del proyecto

## Qué es
API de facturación. Node 22 + Postgres. Sirve al panel interno.

## Comandos
npm install
npm run dev          # local en :3000
npm test             # vitest
npm run db:gen       # genera migraciones

## Convenciones
- Código en inglés, mensajes al usuario en español.
- SQL parametrizado siempre. Nunca concatenar.
- Commits en conventional commits.

## Qué no tocar
- migrations/ — se generan, no se editan a mano.
- .env — nunca se sobrescribe ni se commitea.

## Cuándo está terminado
Compila, `npm test` pasa, y el cambio se probó contra la base local.
```

## De dónde salió cada regla

Ninguna se inventó. Todas vienen de una corrección real:

| Regla | La corrección que la originó |
|---|---|
| Mensajes en español | Escribió un error en inglés en la interfaz |
| SQL parametrizado | Concatenó un `WHERE` con una variable |
| No tocar `migrations/` | Editó a mano una migración ya aplicada |
| Cuándo está terminado | Dijo «listo» con los tests en rojo |

**El método:** durante una semana, cada vez que corrijas al agente, anota la
corrección en una línea. Al final tienes tus reglas, no las de un artículo.

## El checkpoint 1.3 es el que importa

No basta con escribirlas. Comprueba que **una se aplicó sola**:

1. Elige una verificable: «los commits empiezan por feat, fix o chore».
2. Pide algo que la active: «prepara el commit de este cambio».
3. Mira si la cumplió **sin recordársela**.

Si no la cumplió, esa regla está escrita pero no vive. Causas habituales: el
archivo no está donde el agente lo busca, o hay tantas reglas que se diluyen.
