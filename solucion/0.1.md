## El fallo que más cuesta diagnosticar

Dos instalaciones conviviendo. Se comprueba así:

```bash
which -a claude
```

Si devuelve más de una ruta, tienes dos —típicamente el instalador nativo y una
por npm— y la terminal ejecuta una mientras tú actualizas la otra. El síntoma es
que `claude --version` no cambia tras actualizar, o que una función documentada
no aparece.

Deja una sola. Cuál da igual; tener dos, no.

## El orden de diagnóstico

Siempre el mismo, y saltárselo hace perder tiempo:

1. **¿Existe el comando?** → `which claude`
2. **¿Responde?** → `claude --version`
3. **¿Está autenticado?** → `claude doctor`

Cada pregunta tiene un arreglo distinto. El primer checkpoint que falle es el
que hay que arreglar; los siguientes suelen caerse solos al resolverlo.

## La trampa de la variable de entorno

Si tienes `ANTHROPIC_API_KEY` exportada de hace meses, gana sobre la sesión que
inicies ahora. Trabajas contra una cuenta distinta a la que crees. Si algo no
cuadra con la autenticación, ese es el primer sitio donde mirar:

```bash
echo $ANTHROPIC_API_KEY | head -c 12
```
